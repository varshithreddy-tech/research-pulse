# evidence-rules.md — Blogs are leads, papers are evidence

## The rule

1. A **paper** is evidence. A **blog post** is a lead.
2. A blog counts **only if it links to a real published paper** — an arXiv ID, a DOI, an OpenReview page, an ACL Anthology page, a CVF open-access page, an IEEE Xplore page or an ACM Digital Library page — **and that paper is confirmed to exist** (checked against arXiv or Semantic Scholar).
3. When a blog counts, **the paper becomes the item** in the brief. The blog is shown under it as **"Discussed in: <blog title>"**.
4. A blog with **no confirmed paper** is never used as evidence. It is still **saved and counted** ("blogs with no paper") so Kavita can see coverage.
5. A blog that merely **cites** a paper in passing (e.g. in a reading list or a footnote) is not *about* that paper. Link it only if the blog is mainly discussing that paper's work.

## Preprint vs Peer-reviewed (plain facts, not quality labels)

| Situation | Label |
|---|---|
| arXiv paper, and Semantic Scholar shows no venue (or only "arXiv") | **Preprint** |
| arXiv paper, and Semantic Scholar shows a conference or journal venue | **Peer-reviewed** |
| Has a publisher DOI (journal or proceedings) — arXiv's own DOIs (10.48550/arXiv.…) do not count | **Peer-reviewed** |
| OpenReview page, and Semantic Scholar shows it accepted at a venue (e.g. "ICLR 2026") | **Peer-reviewed** |
| OpenReview page with no venue shown, or "Submitted to …" / under review | **Preprint** |
| ACL Anthology, CVF open access, IEEE Xplore, ACM Digital Library | **Peer-reviewed** |

Only use facts that are given to you (DOI, venue, journal reference, site). If none are given, the label is **Preprint**.

## Never

- Never make up a paper link, an arXiv ID or a DOI. Only use links and IDs that appear in the input.
- Never call a paper "validated", "proven", "breakthrough" or similar. Show citations, upvotes, code shared and Preprint / Peer-reviewed as facts.
